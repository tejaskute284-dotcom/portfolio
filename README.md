# Portfolio Website - Tejas Sharad Kute

A professional personal portfolio website for Tejas Sharad Kute, a 2nd-year B.Tech (AI & ML) student, developer, and researcher.

## Tech Stack
- Pure HTML5 + CSS3 + Vanilla JavaScript (ES6 Modules)
- Lenis (via CDN) for smooth scrolling
- GSAP (via CDN) for entrance animations
- Tailwind CSS (via CDN) for utility classes
- tsParticles (via CDN) for subtle hero background
- Google Fonts: "Inter" (body), "Space Grotesk" (headings), "JetBrains Mono" (code/tech tags)

## Design System
- Theme: Dark mode default, light mode toggle
- Max-width 1200px, centered
- Frosted-glass sticky navbar
- IntersectionObserver for scroll animations
- Custom cursor (dot + lagged ring follower)
